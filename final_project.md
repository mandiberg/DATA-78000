## How this fits in the course
You learned some ways to analyze text, numbers, categorical data, and images. You did some exercises to practice using these tools. Now you get an extended period to apply them to your own research interests.

## Assignment Description
I would like you all to create a substantial final project that uses these tools to help augment your own research or creative work. 

This assignment is intentionally open and flexible. The key element is that you need to use one of these tools to answer a research question or advance a creative project. 

Scope: Your project should be ambitious, but achievable over the next two months. A finished smaller project is better than an incomplete over-ambitious project. But take a big swing.

Tools: you need to use at least one AI/ML software package. It can be one of the ones we have demonstrated in class, but you can also use something else if that is more useful for the question you seek to answer. 
An alternative tool could be a variation on one of them that is better suited for your use case, or it could be an entireyl different ML tool. If you are planning to use a different tool, please consult with me first to make sure it is feasible.

## What You Will Learn (AKA Learning Goals)
By the end of this assignment, you will be able to:

- Apply the ML skills you have learned to your own research, allowing you to ask new questions that these new tools allow you to ask.
- Form meaningful questions that the data can answer. 
- Critically reflect on the limits of these tools


## What to turn in
You tell me! Articulate this in your proposal.

## Good Practices (AKA You Should Always...)
- Keep your code readable and reproducible
- Explain each major step in comments: Do this for me, but also for future you (I promise you that you will forget why you did what you did, and you might need to come back to it in the future)
- Be careful with your assumptions (about what is numerical and what is scalar, how you normalize/weight the data)
- Do not treat any model output as an absolute truth: any output is a probabilistic summary, based on the shape of the data it was trained on.
- When your results are weak or ambiguous, say so explicitly. If you know why this is the case, present that information.
