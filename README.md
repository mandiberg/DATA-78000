# DATA-78000
### AI and Machine Learning for Artists and Humanists
----

This site contains course materials for DATA 78000 Special Topics "AI and Machine Learning for Artists and Humanists" at the CUNY Graduate Center

### The course description
Artificial Intelligence and Machine Learning for Artists and Humanists will simultaneously teach students how to use AI and ML tools and how to think critically about their use. One’s ability to think critically about this transformative technology expands the more you learn about how the tools work. The course will be very hands on, with an emphasis on learning the basics of text analysis, topic modeling, data clustering, high-dimensional space, computer vision and image analysis. The goal is for students to gain a better understanding of how these tools work, what their affordances / limitations are, and how to implement them in creative or humanistic projects. The course will include a final project in which students will apply this knowledge to explore a subject or question related to their own research interests.

### Technical Note
The class will be taught in Python. Students should have programming experience, preferably with Python, but Javascript, R, PHP, etc are transferable. The key thing is that students understand functions, control structures, arrays (lists & dictionaries), and how to use a class. If you have questions about prior experience, or for permission, email the instructor.

### Technical Modules

1. Topic Modeling with Gensim 
2. Kmeans clustering with SKlearn
3. Object detection with YOLO
